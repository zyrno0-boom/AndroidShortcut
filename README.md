# Shortcuts for Android

Native Kotlin + Jetpack Compose. Real actions: flashlight, open app, open link, text, dial, alarm, clipboard, wait, Wi-Fi and Bluetooth settings.

## Get the APK without a computer
1. Create a free GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab, run "Build APK" (it also runs on every push to main).
3. When it finishes, open the run and download the "shortcuts-apk" artifact. Unzip it, and install app-debug.apk on your phone (allow "install unknown apps" when asked).

## Or with Android Studio
Open this folder, let Gradle sync, press Run or Build > Build APK(s).
